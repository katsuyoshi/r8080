# Summary

This sample emulated the famouse video game.  
It isn’t working entirely yet.  

## Useg

### Set up

Set up gems and generate the ROM image.  
Follow the below command once.  

```
% bundle
% cd tools
% bundle
% ruby romgen.rb
```

### Run the video game

```
% rake
```

Open 'http://localhost:7521/index.html' in your web browser.  
Or execute below command in another terminal.

```
% rake open
```
